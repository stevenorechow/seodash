SEOdash adds the SEO tools EmDash does not have, and works with the ones it does.

EmDash already gives entries a search title, description, sharing image, canonical address and a "hide from search engines" switch, and it handles redirects, the sitemap and robots.txt. SEOdash keeps no second copy of any of that, so nothing is lost if the plugin is removed.

## What it adds

- **Editor panel.** An SEO score, a content analysis against your target keywords, sharing overrides, robots directives and structured data for the entry. The entry's search title and description are shown as search engines will see them, templates included, and edited in the SEO section of the editor.
- **Titles and meta.** Title and description templates per collection with variables, a home page title and description, and extra robots directives for the site or a collection.
- **Social cards.** Open Graph and X card tags, with a per-entry sharing title and description when sharing should differ.
- **Structured data.** Fourteen schema types per entry (article, product, event, recipe, FAQ, how-to, job posting, video and more) and custom JSON-LD, automatic rules per collection, publisher and local business details, and breadcrumbs.
- **Site audit.** Scores every published entry, lists what to fix first, and shows the result on the dashboard.
- **Instant indexing.** Tells search engines about new and changed pages through IndexNow (Bing, Yandex, Naver and others), on publish or on demand.
- **Publishing rules.** Optionally require a description or image alt text before an entry can be published.

## How it behaves

- With default settings nothing changes on the public site. A tag is printed only for a value you entered or an option you switched on.
- It never changes an entry's SEO fields.
- Every feature can be switched off on the Features tab under Settings. Off means no output and no background work.
- No scripts, styles or other assets are added to public pages.
